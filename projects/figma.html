Overview

This page collects different UI design projects I built in Figma. Each project helped me practice different skills like building components, creating layouts, and making interactive prototypes.

The work covers both course assignments and personal practice projects.

Problem and Context

Each project had its own design challenge. Some needed responsive layouts. Others focused on building a consistent component library. All of them required clear visual communication.

Research and Insights

For each project, I looked at existing patterns and design systems for inspiration. I studied how similar products handle common UI problems like navigation, forms, and content cards.

  • Reviewed design patterns from popular products
  • Studied spacing and typography systems
  • Looked at how other designers organize their Figma files

Ideation and Decisions

I focused on building clean and reusable components. I used auto layout, variants, and consistent naming to keep files organized. Each project started with basic wireframes before moving to high fidelity.

  • Started with basic layout wireframes
  • Built reusable components with auto layout
  • Used consistent naming and color styles

Design Solution

Each project resulted in a complete Figma file with components, page layouts, and an interactive prototype. The designs show clean hierarchy, readable typography, and clear navigation.

  • Organized component libraries
  • Responsive page layouts
  • Clickable prototypes for user flow testing
  • Consistent visual style across screens

Validation and Iteration

I shared designs with classmates and collected feedback on clarity and usability. Based on feedback, I adjusted spacing, button sizes, and navigation patterns.

  • Collected feedback from classmates and instructors
  • Improved component consistency based on review
  • Adjusted layouts for better mobile experience

Results and Learnings

These projects helped me build confidence with Figma as a design tool. I learned to think in components, use auto layout effectively, and create prototypes that communicate ideas clearly.

  • Improved Figma skills including components, auto layout, and prototyping
  • Learned to organize design files for reuse and collaboration
  • Practiced moving from wireframe to high fidelity in a structured way
  • Built a foundation for working with design systems
