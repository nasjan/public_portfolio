UX Research

A usability research project where I evaluated an existing service and provided clear recommendations for improvement.

Overview

In this project I evaluated the usability of an existing service using established research methods. I performed a heuristic evaluation and moderated usability testing to find problems and suggest solutions.

The goal was to practice real UX research methods and deliver results that a development team could act on.

Problem and Context

The service had several usability issues that users noticed during testing. Navigation was unclear, important actions were hard to find, and error messages did not help users recover from mistakes.

This was a course project at Haaga Helia University of Applied Sciences for the UX Research module.

Research and Insights

I used two methods. First, I did a heuristic evaluation using Nielsen's 10 usability heuristics. Then I ran moderated usability tests with participants to observe how they used the service.

  • Heuristic evaluation found issues with navigation, feedback, and error handling
  • Usability testing confirmed the most critical problems
  • Participants struggled with the same 3 to 4 tasks consistently

Key insight: The heuristic evaluation and user testing found many of the same problems. This gave strong evidence for the recommendations.

Ideation and Decisions

I organized the findings by severity and grouped them by area of the interface. This made it easier to see which problems affected users the most and where to focus improvements.

  • Rated each finding by severity from cosmetic to critical
  • Grouped problems by page or feature area
  • Wrote specific, actionable recommendations for each finding

Design Solution

The final deliverable was a research report that included all findings, evidence from testing, severity ratings, and recommendations. Each recommendation was specific enough for a development team to understand and act on.

  • Clear structure with findings, evidence, and recommendations
  • Screenshots and quotes from test sessions
  • Severity ratings for prioritization
  • Short summary for quick review

Validation and Iteration

I reviewed the report with the course instructor and adjusted the clarity of some recommendations based on feedback. The focus was on making sure each recommendation was specific and useful.

  • Improved wording of recommendations to be more specific
  • Added more context to test session findings
  • Checked that severity ratings were consistent

Results and Learnings

This project helped me practice the full UX research process. I learned how to plan research, run test sessions, analyze data, and present findings clearly.

  • Completed heuristic evaluation and moderated usability testing
  • Learned to rate severity and prioritize findings
  • Practiced writing clear and actionable recommendations
  • Understood how research results connect to design decisions
